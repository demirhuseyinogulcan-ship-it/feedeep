Web geliştirme dünyası hızlı hareket ediyor. React ile başlayan yolculuk, bir noktada "peki ya SEO, peki ya performans, peki ya routing?" sorularına çarpıyor. Next.js tam burada devreye giriyor.

Bu bölüm sıfır noktası. Hiçbir şey bilmene gerek yok. Sadece bir bilgisayar ve merak yeterli.

## Next.js Nedir?

Next.js, Vercel tarafından geliştirilen bir React framework'ü. "Framework" kelimesi korkutucu gelebilir ama aslında şu anlama geliyor: React'in üzerine kurulu, hazır kuralları ve araçları olan bir yapı.

Düşün ki React bir motor. Next.js o motoru içine alan, direksiyonu, vitesi, kliması hazır bir araba.

**Next.js'in sağladığı temel özellikler:**

| Özellik | Ne İşe Yarar |
|---------|-------------|
| **Dosya tabanlı routing** | Klasör oluştur → sayfa hazır. Ekstra config yok |
| **Server-Side Rendering (SSR)** | Sayfa sunucuda oluşturulur, SEO için kritik |
| **Static Site Generation (SSG)** | Build zamanında HTML üretir, süper hızlı |
| **API Routes** | Backend API'ları aynı projede yazabilirsin |
| **Image Optimization** | Görselleri otomatik sıkıştırır ve lazy load yapar |
| **TypeScript desteği** | Sıfır config ile TypeScript kullanabilirsin |

Kısacası: React ile yapabileceğin her şeyi yaparsın, üstüne bir de production-ready özellikler gelir bedavaya.

## Node.js Kurulumu

Next.js çalışmak için Node.js gerekiyor. Node.js, JavaScript'i tarayıcı dışında çalıştırmamızı sağlayan bir runtime.

**Adım 1:** [nodejs.org](https://nodejs.org) adresine git.

**Adım 2:** LTS (Long Term Support) sürümünü indir. Bu yazı yazılırken Node.js 22.x LTS güncel.

**Adım 3:** Kurulumu tamamla. Sonra terminali aç ve kontrol et:

```bash
node --version
# v22.x.x gibi bir çıktı görmeli

npm --version
# 10.x.x gibi bir çıktı görmeli
```

Eğer versiyon numaralarını görüyorsan, hazırsın.

> **pnpm Tavsiyesi:** npm yerine pnpm kullanmanı öneriyoruz. Daha hızlı, daha az disk alanı kullanır. Kurmak için: `npm install -g pnpm`

## İlk Next.js Projesini Oluştur

Terminal aç ve şu komutu çalıştır:

```bash
npx create-next-app@latest my-first-app
```

Sana birkaç soru soracak. Şimdilik şu cevapları ver:

```
✔ Would you like to use TypeScript? → Yes
✔ Would you like to use ESLint? → Yes
✔ Would you like to use Tailwind CSS? → Yes
✔ Would you like your code inside a `src/` directory? → Yes
✔ Would you like to use App Router? → Yes
✔ Would you like to use Turbopack for next dev? → Yes
✔ Would you like to customize the import alias? → No
```

Neden bu seçimler?

- **TypeScript:** Hataları daha kodlarken yakalar. Başta zor gibi görünür ama 2 gün sonra geri dönemezsin.
- **Tailwind CSS:** CSS yazmadan stil verebilirsin. `className="text-red-500"` gibi.
- **App Router:** Next.js'in modern routing sistemi. Eski Pages Router yerine bunu kullanıyoruz.
- **Turbopack:** Geliştirme sırasında sayfaları çok daha hızlı derler.

Proje oluşturulduktan sonra:

```bash
cd my-first-app
npm run dev
```

Tarayıcını aç: `http://localhost:3000`

Karşında Next.js'in varsayılan sayfası var. Tebrikler, ilk projen hazır.

## İlk Değişikliğini Yap

VS Code ile projeyi aç:

```bash
code .
```

`src/app/page.tsx` dosyasını bul. İçindeki her şeyi sil ve şunu yaz:

```tsx
export default function Home() {
  return (
    <main className="flex min-h-screen items-center justify-center">
      <h1 className="text-4xl font-bold">
        Merhaba Next.js! 🚀
      </h1>
    </main>
  );
}
```

Dosyayı kaydet (Ctrl+S). Tarayıcıya dön.

Sayfa otomatik güncellendi. Buna **Hot Module Replacement (HMR)** deniyor — değişikliklerin anında yansıması. Sayfayı yenilemen gerekmez.

Az önce şunları yaptın:
1. Bir React component'i yazdın (`Home` fonksiyonu)
2. JSX kullandın (HTML benzeri sözdizimi JavaScript içinde)
3. Tailwind CSS class'ları ile stil verdin
4. HMR'ın çalıştığını gördün

Hepsi bu. İlk Next.js sayfan yayında.

## Geliştirme Ortamı İpuçları

VS Code kullanıyorsan bu extension'ları kurmanı öneriyoruz:

- **ES7+ React/Redux/React-Native snippets** — `rafce` yaz, Tab'a bas, component hazır
- **Tailwind CSS IntelliSense** — Class isimleri otomatik tamamlanır
- **Pretty TypeScript Errors** — TypeScript hatalarını okunabilir yapar
- **Error Lens** — Hataları satır üzerinde gösterir

Terminal kısayolları:
- `Ctrl + ~` → VS Code içinde terminal aç
- `Ctrl + C` → Çalışan sunucuyu durdur
- `npm run dev` → Geliştirme sunucusunu başlat
