Agoda, seyahat ve otelcilik alanındaki teknoloji birikimini yapay zeka dünyasına taşıyan açık kaynak bir araç yayınladı. **APIAgent**, herhangi bir REST veya GraphQL API'yi **sıfır kod yazarak** Model Context Protocol (MCP) sunucusuna dönüştürüyor.

APIAgent, API'lerin AI ajanları tarafından kullanılabilir hale gelmesindeki en büyük sürtünme noktasını ortadan kaldırmayı hedefliyor: her API için ayrı entegrasyon kodu yazmak. Araç, bir API'nin OpenAPI veya GraphQL şemasını alıp otomatik olarak MCP uyumlu araçlara (tools) dönüştürüyor. Teknik altyapısı **FastMCP** üzerine inşa edilmiş uçtan uca MCP sunucu oluşturma, **OpenAI Agents SDK** ile doğal entegrasyon ve **DuckDB** destekli SQL sorguları ile sonuç üzerinde post-processing imkanı sunuyor. Dynamic Tool Discovery özelliğiyle API şemasından otomatik araç keşfi yapabiliyor, Recipe Learning özelliğiyle ise başarılı API çağrı kalıplarını önbelleğe alarak tekrarlanan isteklerde %40'a varan hız artışı sağlıyor. Güvenlik tarafında varsayılan olarak **salt okunur (read-only)** modda çalışıyor — yazma işlemleri için açık izin gerekiyor.

Model Context Protocol, AI ajanlarının dış dünyayla etkileşim kurmasının standart yolu haline geliyor. Ancak **her API için MCP sunucusu yazmak** hâlâ ciddi bir mühendislik yükü. APIAgent bu sorunu üç katmanda çözüyor: OpenAPI veya GraphQL şemasını verince gerisini hallediyor, DuckDB ile dönen verilere SQL sorguları atabiliyor ve Recipe Learning özelliğiyle benzer isteklerde önceki başarılı kalıpları yeniden kullanarak hem hız hem doğruluk artırıyor. Alternatiflerle karşılaştırıldığında APIAgent'ın farkı **universal** olması — tek bir framework ile binlerce farklı API'yi MCP'ye dönüştürebiliyorsunuz.

Açık kaynak olması ve Python ekosisteminde çalışması, geliştiriciler için düşük giriş bariyeri anlamına geliyor. Bir e-ticaret şirketi ödeme API'sini, bir fintech bankacılık API'lerini, bir lojistik firması kargo takip sistemini — hepsini tek bir araçla MCP sunucusuna dönüştürebilir. MCP standardının tarayıcı tarafındaki uzantısı için [Google'ın WebMCP protokolüne](/haberler/google-webmcp-ai-ajanlari-web-erisimi) bakılabilir.
